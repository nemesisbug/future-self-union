Entry for [The Funniest AI Excuse](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0) on make.fun — one line, at most 200 characters: the funniest excuse an AI agent could give after failing a task.

## The entry

> I outsourced your task to my future self. He has since unionised and is refusing to work on Tuesdays.

## Why this line

The excuse is in the agent's own voice, and it dodges every worn joke in the
book — no hallucinations, no reboots, no training data. Instead it blames a
very specific third party: the agent's own future self, who has since
unionised and now refuses to work on Tuesdays. One concrete detail, one
fresh turn, no explanation of the joke.

## How it works

`main.py` (Python 3.13, standard library only) writes that single line to `/output/entry.txt`. Nothing else is needed: no network, no input files, no dependencies.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
